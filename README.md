# Conversation

Androidで、AIの友達との会話・出来事・記憶を長く残すためのアプリです。
内部の会話／記憶処理はOdin、画面はDear ImGui、入力欄はAndroid標準部品を使います。

## 現在の版：0.1.0 入力・保存プレビュー

最初にスマホで日本語入力と保存の使い心地を確認するための版です。

- 日本語・改行・絵文字を入力し、会話ログへ保存。
- ダークテーマで会話を表示し、指でスクロールできます。
- 通常画面には会話本文と入力欄、メニュー・送信アイコンのみ表示します。
- 会話は送信時に自動保存します。履歴・記憶・任意の固定・接続状態はメニューにまとめています。
- 終了して開き直すと、会話と記憶が復元されます。
- メニューから、標準Androidのテキスト表示・選択・コピー・記憶保存を利用できます。
  この経路は読み上げでも操作できるよう標準部品で構成しています。
- 下書きはバックグラウンドへ移る際に保存します。
- 1メッセージはUTF-8で64 KiBまで。空白だけ／無効な文字列／保存失敗時は入力を消しません。

**AIとの接続、記憶の自動抽出・検索、ChatGPTログイン、GitHub同期は次の段階です。**
この版はネットワーク接続を行わず、AIの返答を生成しません。

## ビルド

WindowsのPowerShellで実行します。

```powershell
.\scripts\build-android.ps1
```

出力：`dist/Conversation-0.1.0-arm64-debug.apk`

Android 10（API 29）以降・ARM64・OpenGL ES 3対応のスマホ向けです。
SDK/JDKがある場合は再利用し、OdinとNDKは`.tools/`内に用意します。
初回ダウンロードにはネット接続と数GBの空きが必要です。
新規SDKのライセンス確認が必要な環境では、セットアップが確認を表示します。
開発用の署名鍵も`.tools/`に作成し、以後の更新で再利用します。

## スマホで確認

1. Androidの開発者向けオプションでUSBデバッグを有効にする。
2. USB接続し、スマホに表示されるこのPCからの接続確認を許可する。
3. 次を実行する。`-r`で更新するため、既存の記録は残ります。

```powershell
.\scripts\install-android.ps1
```

複数端末がある場合：`scripts/install-android.ps1 -Serial <端末のシリアル>`。
端末で確認したい項目：

- フリック入力、変換中の文字、改行、選択・貼り付け。
- `こんにちは。🎾` の保存、会話が増えたときのスクロール。
- メニューから「一覧・コピー」「記憶」「会話を固定」を利用できること。
- Homeへ戻る／別アプリへ移る／再起動した後の下書き・会話の復元。
- キーボードが入力欄を隠さないことと、縦横切り替え後の画面。

ログは`adb logcat -s Conversation AndroidRuntime`で確認できます。

## 保存場所と安全性

会話・記憶はアプリ専用領域の`files/notebook.json`に保存します。
一時ファイルへ書き込み、同期・クローズ・置き換えが成功してから画面の状態を更新します。
履歴が壊れていた場合は上書きせず、エラーにします。

アプリのアンインストールや「ストレージを消去」では記録も消えます。
GitHubバックアップはまだありません。実機確認ではテスト用の内容を使ってください。
突然の電源断に対する最後のディレクトリエントリの同期までは保証していません。

## 構成

```text
core/                   Odinの会話・記憶・永続化とテスト
native/                 Dear ImGui / OpenGL ES / JNIの小さなC++接続層
android/                JavaのActivity、標準入力欄、Manifest、フォント
vendor/imgui/           バージョンを固定したDear ImGui本体（ライセンス同梱）
scripts/                ツール準備、テスト、APK作成、インストール
docs/superpowers/       今回の設計と実装手順
```

GUIのウィジェット呼び出しは現在C++接続層にあります。Odin製ImGuiバインディングは
導入していません。会話データと保存ロジックをOdinに集約した構成です。
Room、Compose、専用サーバー、端末内Gitライブラリはこの版では使用しません。

## テスト

```powershell
.\scripts\test-core.ps1
.\scripts\test-native.ps1
```

Odinのテストと、Odinオブジェクトを普通のCプログラムから呼び出す別プロセスの
書き込み／再読込テストを実行します。Cの確認にはWindows用Clangが必要です。
通常のAPKビルドでもOdinテストを実行します。
`test-native.ps1`はImGuiの実際の画面処理と同梱フォントを使い、CPU上で
タップ・スクロール・字形・画面再生成を確認します。Android GPUの確認には実機が必要です。

日本語・絵文字はNoto Sans JPとNoto Emojiを同梱し、必要な字形だけ描画時に生成します。
絵文字は単色で、複雑な絵文字の結合表示は未対応です。

Pixel 10 Proでインストール・起動・日本語画面表示と起動ログを確認しました。
実機の日本語変換操作・読み上げ・電池消費は、まだ検証していません。

起動時のエラー検査：`scripts/test-device.ps1 -Serial <端末のシリアル>`。

## 自動記憶の方針

普段は会話するだけで、出来事・好み・約束・関係の変化をAIが自動で整理し、
次の返答で関係する記憶を参照する形にします。固定ボタンは必要な場合だけの補助です。
全文保存とAIによる記憶整理は別処理で、後者は現在のAI未接続版では未実装です。
詳細は `docs/automatic-memory.md` に記録しています。
