# Conversation

AndroidでAIの友達と会話し、出来事・好み・約束を自動で記憶するためのアプリです。
Odinが会話・記憶・SQLiteを管理し、Dear ImGuiでチャットを描画します。
Android標準の入力欄、ChatGPTのサブスク認証を組み合わせています。

## 0.3.0 人物・Gitプレビュー

- 暗いチャット画面に本文と入力欄、メニュー・送信アイコンだけを表示。
- メニューから人物切り替え、ChatGPTログイン、モデル選択、表示設定、Gitバックアップ。
- 人物ファイルを読み込み、基本プロフィール・口調・考え方と、出典付きの過去の出来事を引き継ぎます。
- 人物と非公開GitHubリポジトリを一対一で固定し、会話・記憶の差分を自動保存します。
- ユーザー発言を先に保存し、実際の返答を受信。完了した返答だけを記録します。
- 記憶は差分から自動で整理。手動登録・全文一覧・全文コピーは設けません。
- 出来事・事実・約束・解釈を分け、現実／創作／共有体験、根拠の発言ID、更新履歴を保持。
- 推測による事実の上書きや、異なる人物・事項の上書きを保存時に拒否。
- SQLiteへ1件ずつ保存し、画面は最大80件のページで古い会話も読めます。
- 日本語の文字索引と人物・キー・時間を使い、関連する記憶と原文を範囲を絞って取得。
- 文字サイズ16〜28（初期20）、メッセージ間隔8〜24（初期12）を保存。

## ChatGPTへ接続

1. メニュー → ChatGPT → **Continue with ChatGPT**。
2. ブラウザで自分のアカウントを選び、Conversationで利用枠を使う許可をする。
3. 結果ページの **Conversationに戻る** を押し、アプリで接続を完了する。
4. 必要ならメニュー → ChatGPT → モデルを選ぶ。

アカウントの利用条件と利用枠に従います。会話の返答に加え、未整理の差分がある場合は
一度の処理で最大3バッチの記憶整理にもモデルを使います。利用状況は同じメニューから確認できます。
APIキーは要求しません。接続情報はAndroid Keystoreで暗号化し、バックアップには含めません。
ブラウザの裏ではAndroidが通信を制限することがあるため、認証の完了はアプリに戻ってから行います。

応答停止・通信失敗では途中の返答を確定せず、ユーザーの原文は残します。
記憶整理の失敗は未処理ジョブとして残し、後続の会話やChatGPTメニューから再試行できます。
端末を再起動しても未処理状態は保持されます。

## 保存とバックアップ

既存の`files/conversation.sqlite3`は「これまでの会話」として維持します。
新しい人物は`files/people/<UUID>/conversation.sqlite3`へ分離します。WALとトランザクションを使います。
旧版の`notebook.json`は起動時に一度だけ移行し、元ファイルは削除しません。
既存の旧固定データも出典付きの互換記録として保全します。

人物を作る手順:

1. [人物形式](docs/formats/person-v1.md)に合わせたUTF-8のMarkdownをスマホへ保存。
2. GitHubで人物専用の**空の非公開リポジトリ**を用意。
3. メニュー → 人物 → 人物ファイルを読み込む。プレビュー後、リポジトリURLとGitHubトークンを入力。
4. トークンは対象リポジトリのContentsをRead and write、MetadataをReadにします。

元ファイルは残し、過去の記載を実際の会話ログとして捏造せず、資料由来の記憶として取り込みます。
人物の切り替えで会話、記憶、下書きも切り替わります。応答・記憶整理中は切り替えません。
常用メニューに記憶一覧は置かず、会話に関連する記憶を自動で参照します。

Gitには人物ファイル、会話用プロフィール、会話原文・出来事・記憶の変更履歴、復元用情報を保存します。
会話後の待機中（約2分）とアプリを離れるときに保存し、手動保存も可能です。
別の編集による競合は上書きせず停止し、未保存分は端末に残します。詳細は[Git保存形式](docs/git-person-archive.md)。
認証情報は端末内で暗号化し、Gitへ含めません。GitHub認証はChatGPT認証とは別です。

メニュー → Gitバックアップ → 端末からZIPを書き出すで、選択中の人物を書き出せます。
中身は整合性の取れたメタデータと、目標1MiB・最大2MiBのJSONL分割データです。
Gitからの取り込み・復元画面と、複数端末で同時に編集する同期はまだありません。
自動保存は起動中の待機タイマーと画面を離れる際の試行です。アプリ終了中の定期通信は行いません。
この公開ソースリポジトリへ個人の会話・記憶・接続情報をpushしないでください。
アンインストールやアプリのストレージ消去では端末の記録が消えます。

## 実装の範囲と制約

- 現在の検索はFTS5文字索引と構造化検索です。埋め込みベクトルやグラフDBは使いません。
- 記憶は出典を追えるようにしていますが、モデルの意味解釈の正しさは保証できません。
- 再処理による同一ジョブの二重反映は防止。異なる会話間の意味的な重複判断はモデルにも依存します。
- 古い文脈や抽出バッチ内の長文は、一部の抜粋になる場合があります。原文はDBに残ります。
  今回ユーザーが送った発言は、切り詰めずモデルへ渡します（1発言UTF-8で64KiBまで）。
- 単色のNoto Emojiを使い、複雑な絵文字の結合表示には制限があります。
- サブスク認証・AI品質の検証状況は`docs/validation.md`を参照してください。

## ビルドとスマホへのインストール

Windows PowerShellで実行します。初回はSDK／NDK／Odin等の準備に通信と数GBの空きが必要です。
既存SDK/JDKは再利用し、追加ツールは`.tools/`に保管します。
新規SDKでライセンス確認が必要な場合はセットアップが確認を表示します。

```powershell
.\scripts\build-android.ps1
.\scripts\install-android.ps1
```

出力は`dist/Conversation-0.3.0-arm64-debug.apk`。
Android10/API29以降・ARM64・OpenGL ES3向けの開発用APKです。
USBデバッグを有効にし、このPCをスマホで許可してからインストールしてください。
複数端末の場合は`install-android.ps1 -Serial <シリアル>`を指定します。

## 検証

```powershell
.\scripts\test-core.ps1
.\scripts\test-native.ps1
.\scripts\test-connection.ps1
.\scripts\test-device.ps1 -Serial <シリアル>
.\scripts\test-person-device.ps1 -Serial <シリアル>
```

- Core: 移行・破損データ保全・2万件の会話／記憶・人物資料の出典・差分の再生・ロールバック。
- Native: 人物切替の失敗復帰、最大80件の表示、ページ位置、途中の返答、文字サイズと画面再生成。
- Connection: OAuth/SSE、人物ファイル・一覧、プロフィール注入、Gitの競合・中断復帰・公開先拒否。
- Device: 起動と初期化エラーの確認。実機の実通信や長期的な会話品質を代替するテストではありません。
- Person device: 署名済みテストAPKから合成人物だけを使い、Keystore・JNI取り込み・切替・書き出しを実機確認。実行時はアプリを閉じます。

## ソース構成

`core/`がOdinの保存・記憶、`native/`がC++の描画とJNI接続、`android/`がOS入力・認証・通信、
`vendor/`がライセンス付きの固定依存、`scripts/`がビルドと検証です。
画面ウィジェットは現在C++接続層から呼び出し、Odin製ImGuiバインディングは導入していません。
