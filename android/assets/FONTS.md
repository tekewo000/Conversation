# Bundled fonts

Both font families use the SIL Open Font License 1.1; see their OFL files here.
The regular instances were generated at `wght=400` with fontTools 4.68.0 from
Google Fonts' variable TrueType files on 2026-11-13:

- https://github.com/google/fonts/tree/main/ofl/notosansjp
- https://github.com/google/fonts/tree/main/ofl/notoemoji

The glyph outlines are unchanged apart from selecting an existing weight.
Noto Emoji provides monochrome outlines; this build does not render color emoji.

SHA-256 of the packaged regular instances:

- NotoSansJP-Regular.ttf: `1316f70dc30b96c13aa814f9f99053ded4caa31323249cf4d91c14e728cd2e83`
- NotoEmoji-Regular.ttf: `fe2a787aa5c569188f4a188c5a9731dc7320a9a1a3fe63ba7dccd80088ae4804`
