# Conversation v0.6.0 — 端末内のUSearchによる長期記憶検索

長期記憶にUSearchの意味検索を追加しました。日本語の言い換えを端末内モデルで検索し、従来のSQLite全文検索と組み合わせます。

- Ruri v3 30mの量子化モデルを端末内で実行します。初回にモデルとトークナイザーを合計38,880,454バイト取得し、サイズとSHA256を検証します。検索用の追加API料金はなく、記憶本文を検索サービスへ送信しません。
- 人物ごとに検索用のベクトルを保存し、記憶の追加・更新に合わせて背景処理で索引を更新します。上書きされた旧記憶のベクトルは取り除きます。
- 元の記憶と根拠の会話はSQLiteで保持します。意味検索の候補は現在の記憶に照合し、出典と一緒に返答へ渡します。
- 索引の準備中や失敗時も、従来の検索で会話を続けられます。検索キャッシュは破損時に再生成し、人物のGit・ZIPバックアップには含めません。
- 0.5.3の人物アイコン、今の気持ちの表示、短期記憶30往復を引き継ぎます。
