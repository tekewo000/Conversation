# Conversation v0.6.5 — 会話を根拠にした関係の積み重ね

その場の気持ちとは別に、相手への信頼・心を開ける範囲・その理由を、根拠の会話とともに保持するようにしました。

- 謝罪を受け止めて落ち着くことと、信頼が回復することを区別します。対立や仲直りの経験は、後の返答や人物像の振り返りへ渡します。
- 関係の更新には、今回の記憶整理に含まれる双方の発言を必要とします。関係の改善だけで好意や持続的な性格を自動的に変える扱いにはしません。
- 根拠の会話が直近30往復から外れた後も参照できます。過去の人物像を振り返る際は、その時点までの関係と根拠だけを渡します。
- 既存のバックグラウンド記憶整理で更新するため、通信回数は増えません。既存の会話・記憶は引き続き読み込めます。
