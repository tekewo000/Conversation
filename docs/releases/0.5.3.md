# Conversation v0.5.3 — 人物アイコン・今の気持ち・短期記憶30往復

- 人物ごとに写真・画像からアイコンを設定できます。AIの吹き出し左のアイコンをタップ、または「人物 → 人物アイコンを設定」から変更・解除できます。
- 最新のAI発言には、アイコンの下に今の気持ちだけを表示します。理由・きっかけの出来事・根拠の会話は短期記憶として保存し、返答へ引き継ぎます。
- 短期記憶を過去30往復＋今回の入力（通常の交互会話で最大61発言）に拡大しました。直近の原文予算も拡げ、長文やJSONエスケープによって発言数が早く減ることを防ぎます。
- アイコンは端末内で256×256のPNGへ変換して人物ごとに保存し、再起動・人物切り替え・ZIPとGitバックアップへ引き継ぎます。

## インストールと検証

Android 10以降・ARM64向けの署名済みAPKです。アンインストールせず上書きしてください。DBは既存のschema 4を使用し、会話原文を保持します。

Core 37件とC ABIの再起動試験、Native、Connection 59件と関連ホスト試験、エミュレーターのCompose/UI 18件、Releaseビルド・署名・16KiBアライメントを確認しました。既存のシンボリックリンク作成試験はホストの制約でスキップしています。

実機へのインストール、実際のモデルによる感情表現の自然さ、非公開GitHubへのアイコン同期は未検証です。長期記憶の検索は従来のSQLite全文検索のままで、この版にUSearchは含みません。過去の長文は1発言あたり最大2048文字をモデルへ渡し、原文は全文保存します。記憶の更新はバックグラウンド処理のため、次の返答に更新が間に合わない場合があります。
