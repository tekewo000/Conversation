# Conversation v0.6.11 — 自動バックグラウンド整理・大きな一括処理

- アプリ起動時と返答保存後に、未整理の会話を自動で整理します。画面に依存するスレッドからWorkManagerへ移し、別アプリへの切り替えや画面終了後も処理を継続・再試行します。
- 16発言ごとの固定区切りを廃止しました。原文の文章量を見て最大256KiBまでまとめ、収まる場合は残り全体を一度に整理します。長すぎる場合だけ分割し、失敗時も原文と未処理位置を保持します。
- 記憶画面を開いたままでも、保存済みの進捗・中期記憶を自動で更新します。手動で閉じて開き直す必要はありません。
- バックグラウンド用の接続と通常の会話が、更新済みの認証情報を共有します。ログアウトすると整理も停止します。
- 大きな整理だけ通信の待機上限を5分へ拡げ、通常会話の2分上限は保ちます。実機では残り791発言を一括整理し、約2分25秒で2,333／2,333発言まで完了しました。途中でアプリをバックグラウンドに移した後も処理を継続しました。

実機の未整理ジョブは0件、中期記憶は29件になったことを確認しました。コア48件、Composeの全45件と、追加の自動更新を含むActivity試験11件が通過しています。

一時停止を選んだ場合は再開操作まで停止します。Androidによる省電力・通信状態・実行枠の制御で、開始や再試行が待機することがあります。処理中ずっとアプリを表示しておく必要はありませんが、OSの「強制停止」後は再度アプリを開く必要があります。

原文と出典の検証は維持しています。要約の正確さ、すべての出来事の抽出、任意の長さの会話を必ず一回で処理することは保証しません。記憶整理はChatGPTの利用枠を使います。
