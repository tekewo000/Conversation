# Conversation v0.10.0

写真用の既存復元キーで、会話・記憶・人物情報・下書き・全添付・DB/検索索引・整理作業データ・Git/ZIPバックアップを暗号化します。従来の写真キーと画像を引き続き使えます。

旧データは利用前に検証付きで移行します。キーの紛失・不一致、改ざん、判別できない孤立データがある場合は原本を保持して停止します。復元キーの読込み、保存失敗時の下書き保持、中断した保存からの再開も含みます。

PC用のバックアップツールを同梱しました。既存Gitの全ブランチ・タグ・コミットとGit LFS実体を暗号化して別の非公開リポジトリへ移し、移行先から取り直して復元照合できます。アプリは検証済みの移行先へ接続し直して通常の差分保存を再開します。元Gitを変更・削除することはありません。

- [暗号化の範囲と方式](../data-encryption.md)
- [移行・PC復元手順](../git-backup-migration.md)

検証: Core 74試験、native試験、Java試験、エミュレータ83試験、Git全履歴/LFS/復元・改ざん・再開試験を実行。署名済み旧Releaseからの上書き更新、写真キー・会話・下書きの保持、Release内の暗号化ZIP書き出し、ONNX JNI名とモデル推論・起動を公開前に確認します。

実ユーザーのGitリポジトリでの移行、実GitHub/LFS認証、物理端末の使用感・停電時の耐久性、初回モデルダウンロードは未検証です。モデル推論試験にはサイズとSHA256を照合した公開モデルを事前配置しています。以前のGit・ZIP・cloneの平文は、この更新だけでは消えません。
