# Conversation v0.5.0 — 会話の現在地と体験の記憶

会話が続いても候補の順番・決定・保留事項を引き継ぎ、出来事・語られた感情・場面を関連付けて記憶するB方式を追加しました。

- 会話の現在地を毎回の返答に渡し、必要な根拠と前後の原文を取得します。
- 進行中の話の主要な根拠を優先し、取得枠を分け合って古い話が押し出されにくくしました。
- 感情の明示と推測、当時と現在、現実・創作・会話上の共有体験を分けて扱います。
- 既存の記憶整理の通信にまとめ、追加のモデル呼び出しは設けていません。入力の利用量は増えます。
- 記憶と現在地は同じトランザクションで確定し、失敗時は原文と前回の状態を残します。Git差分とZIPにも保存します。

## インストール

Android 10以降・ARM64向けの署名済みAPKです。既存のRelease版へ上書きしてください。アンインストールやストレージ消去はしないでください。
DBをschema 4へ移行します。旧APKはschema 4を開けないため、ダウングレードには対応しません。
