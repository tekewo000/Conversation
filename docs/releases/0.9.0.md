# Conversation v0.9.0 — 人物・記憶・設定・バックアップの管理画面を刷新

- チャットのメニューから「管理」を開き、人物・記憶・設定・バックアップへ進める構成にしました。チャットの表示、入力、添付、返信の表示は維持しています。
- 人物の追加・切り替え・読み込み・削除・アイコン変更を「人物」に、ChatGPT・モデルと応答・画像生成API・文字サイズを「設定」にまとめました。
- 記憶の内容と整理状況を分け、短期記憶は発言ごとの原文、中期記憶は体験の一覧と階層として表示します。人物アイコンから記憶を開く操作も残しています。
- 「戻る」で親の画面と閲覧位置へ戻れます。管理画面の開閉で下書きを失わず、画面を離れた後の記憶読み込み・再整理・認証結果が、移動先の画面や入力を上書きしないようにしました。
- 秘密入力のマスクと画面キャプチャ抑止を維持し、取り消した入力値を破棄します。会話・記憶のDB、バックアップ形式、既存の設定は変更していません。

Composeの全68件と、システム文字倍率1.5での管理画面の操作試験が通過しています。実機での操作感、実際のOAuthブラウザ認証・ChatGPT通信・有料画像生成・Gitアップロードは今回の検証に含めていません。

Releaseビルドのコア70件、ONNX JNI名、署名済みAPKの起動と実モデル推論を検証しました。モデルは固定版のサイズ・SHA256を照合して検証環境へ配置しており、初回ダウンロードは未検証です。公開済みv0.8.3からの削除なし更新と、最適化されたRelease上の管理画面の操作も検証しています。
