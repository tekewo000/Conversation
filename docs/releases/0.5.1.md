# Conversation v0.5.1 — 次の会話を待たせない記憶整理

返答の後、記憶整理が終わるまで次を送れなかった動作を修正しました。

- 返答を保存したら送信を再開し、記憶・現在地・人物像の整理を別のワーカーで進めます。返答と整理のHTTP通信も並行して実行します。
- 整理は一つずつ順番に行い、要求が重なったら次の1件にまとめます。未処理の会話範囲はDBに残します。
- OAuth更新とDB保存は直列化します。返答の停止は返答通信だけ、ログアウト・画面破棄は全通信を停止します。人物変更は整理が終わるまで待ちます。
- 発言ID・記録時刻などの内部情報を会話本文から分離しました。途中のストリーム、保存前、既存の履歴表示で内部ラベルと制御記号を除きます。過去の原文を一括書き換えたり削除したりはしません。
- 報告された無関係な中国語の先頭行を表示・保存から取り除きます。その行の発生元は未特定で、原因の修正を確認したとは扱っていません。中国語全般を削る処理はありません。
- 受信した最終返答と内部用チャネルを分けて扱います。

Android 10以降・ARM64向けの署名済みAPKです。アンインストールせず上書きしてください。DB形式は0.5.0と同じschema 4です。
