# Conversation v0.10.1

「人物 → 名前を編集」から、選択中の人物の表示名を後から変更できます。変更した名前は人物一覧、画面の見出し、会話の人物アイコン、削除確認などへ反映され、再起動後も保持されます。

表示名は写真と同じ復元キーで暗号化して保存し、Git・ZIPバックアップにも含めます。会話が増えていない場合でも名前の変更をGitへ保存します。

人物ID、元の人物資料、会話・記憶、写真キー、Git保存先は維持します。AIへ渡す元の人物情報の名前は変更しません。

入力検証・保存失敗時の保持・キーとIDの維持・バックアップ復元、UIでの編集と再起動後の下書き保持を検証しました。Core 74試験、Java各スイート、エミュレータ84試験、Git全履歴・LFS・PCツールの試験が成功しています。

署名済みv0.10.0からの上書き更新でUID・写真キー・会話・下書きを保持し、最適化済みAPK内で表示名の変更・永続化・暗号化ZIPを確認しました。ONNX JNI名、起動・モデル推論、画像保護のRelease試験も成功しました。物理端末は接続が切れており、新版のインストールと表示名編集は未確認です。実GitHubへの表示名変更の同期は今回試していません。
